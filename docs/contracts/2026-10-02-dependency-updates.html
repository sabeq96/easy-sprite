Update all packages to newest

agreed2026-10-02docs/contracts/2026-10-02-dependency-updates.html
Problem
Seven npm packages and six GitHub Actions are behind latest, and four Dependabot PRs sit open against main. F1 F2 F3
Goal
Every npm package and GitHub Action is on its newest version, breaking changes are flagged in one PR, and anything needing a bigger redesign is listed as a followup.

What gets built

newchangedremoveduntouched

One branch off main bumps every package, one task at a time, each checked with lint, build and unit tests. A package whose upgrade needs more than a small fix stays on its old version and goes into the PR's followup list. CI and Pages move to Node 24 and all six Actions to their latest major.

Scope

In

  • Work on a new branch off main, one PR D1
  • Bump every npm dependency to latest, including majors (TypeScript 7, Babel 8, @types/node 26) and spec floors that lag the lockfile (lucide-react, oxlint, react, react-dom, @types/react, @types/react-dom)
  • Bump all six GitHub Actions to latest major and CI and Pages to Node 24 D2
  • Small fixes a bump needs: config edits or about 10 call-site fixes D3
  • Breaking-changes table and followup list in the PR description, flagging the unchecked React Compiler risk D4 D3

Out

  • Redesigns or large migrations a bump would need; package stays old, listed as followup Q3
  • Closing Dependabot PRs #7, #9, #12, #15 before merge; done only after you confirm Q1
  • Changing .github/dependabot.yml Q1
