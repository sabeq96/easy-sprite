User-configurable defaults (#19)

agreed2026-10-03approved 2026-10-03 (with amendment A1)docs/contracts/2026-10-03-user-defaults.html
Problem
Every starting value is a hardcoded constant: the new-sprite and new-sheet tile size and count, grid and chessboard size, grid on/off, preview FPS, palette and onion skin. The editor.defaultCanvasSize setting key exists, but nothing reads it. F1 F4 F5 F6 F7 F8 F9 F10
Goal
A Defaults section on the Settings page sets each of those values. Each one can be reset to its built-in value, is saved in IndexedDB and is included in backups. New Sprite/Sheet dialogs and every freshly opened sprite or sheet start from them.

How this contract was decided: you asked me to make the design decisions myself. Every D# below is marked (delegated) and gives my reasoning and the alternatives I rejected. Approving the contract approves those decisions; change any row before approval.

What gets built

newchangedremoveduntouched

Settings gets a Defaults card with 11 values in 4 groups. Each group has a reset button that is enabled only when one of its values differs from the built-in. Changes save at once into a single app.defaults row in the existing settings table, which is why backup and restore already carry them. A small store holds the resolved values. The sprite and sheet loaders wait for that store before opening, so a document never opens with the built-in values first. Each editor module applies its own values whenever a sprite opens.

Scope

In

  • All 13 defaults listed in the issue, editable and resettable on the Settings page
  • One stored row, validated per field D1 D3
  • Applied to the New Sprite/Sheet dialogs and to every sprite and sheet open D4 D5
  • Included in backup and restore, and live after a restore or clear D10
  • Removing the dead editor.defaultCanvasSize key D12

Out

  • Remembering the last used values automatically (only explicit defaults) Q2
  • Separate editor and builder values for grid and chessboard Q6
  • Defaults for zoom, primary/secondary colour, brush size (A1), mirror, or any other tool setting Q7
  • The other unused keys (view.grid, view.onion, palette.active) Q12
  • Theme (it already persists in localStorage, separately) Q12
  • Repository fallbacks (createSprite/createSpritesheet without options keep the built-ins) Q4
  • Syncing defaults across open tabs Q2
